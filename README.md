# НарядAI

Мобильная веб-система для выдачи и контроля производственных нарядов. Интерфейс построен на Blazor Web App с интерактивным серверным рендерингом; PWA-манифест позволяет установить приложение на Android. Состояния нарядов синхронизируются через SignalR.

## Требования

- .NET SDK 10.
- PostgreSQL 15 или новее.
- Браузер с поддержкой WebSocket. Для установки PWA на телефон нужен HTTPS; `localhost` подходит только для локальной разработки.

## Локальный запуск

1. Создайте пустую базу PostgreSQL.
2. Перейдите в корень репозитория и задайте строку подключения в текущем окне PowerShell. Не сохраняйте пароль в Git:

   ```powershell
   $env:ConnectionStrings__DefaultConnection = "Host=localhost;Port=5432;Database=naryadai;Username=postgres;Password=<ваш пароль>"
   ```

3. Запустите приложение:

   ```powershell
   dotnet run --project .\NaryadAi\NaryadAi.csproj --launch-profile http
   ```

4. Откройте адрес, указанный в сообщении `Now listening on` (по умолчанию `http://localhost:5237`). При первом запуске EF Core применит миграции и создаст стартовую учетную запись администратора для пустой базы.

В текущей демонстрационной авторизации начальные учетные данные этой локальной учетной записи — `admin` / `admin`. Используйте их только на локальной тестовой базе и смените пароль до подключения реальных пользователей или публикации приложения.

## Установка на телефон

Откройте опубликованный HTTPS-адрес в Chrome на Android и выберите **Установить приложение** или **Добавить на главный экран**. Для локальной проверки на телефоне запустите сервер с доступом по локальной сети и используйте HTTPS-сертификат, которому доверяет телефон. Обычный HTTP по IP-адресу не позволяет установить PWA.

Сервис-воркер кэширует статические файлы и показывает страницу недоступности при потере связи. Рабочие данные хранятся на сервере; автономная синхронизация нарядов в этой версии не реализована.

## Основные страницы

- `/login` — демонстрационный вход.
- `/master` — выдача и канбан-доска нарядов.
- `/worker` — действия назначенного исполнителя и форма выполнения.
- `/profile` — профиль текущего пользователя.
- `/reports` — отчет за период и экспорт в Excel.
- `/admin/employees` и `/admin/dictionaries` — справочники и сотрудники.

ИИ-проверка использует правила локально, если внешний провайдер не настроен. Для подключения Claude задайте `Ai__AnthropicEndpoint`, `Ai__ApiKey` и при необходимости `Ai__Model` через переменные окружения; не отправляйте наружу персональные данные.

## Миграции и сборка

Миграции применяются автоматически при запуске приложения. Проверить сборку можно из корня репозитория:

```powershell
dotnet restore .\NaryadAi\NaryadAi.csproj
dotnet build .\NaryadAi\NaryadAi.csproj
```

Перед демонстрацией создайте отдельную тестовую базу, чтобы не смешивать демонстрационные записи с производственными данными.

## Данные для демонстрации кейса

На пустой базе можно включить детерминированный набор для защиты проекта. Он создаётся только в окружении `Development` и только при явном параметре `Seed__EnableDemoData=true`:

```powershell
$env:Seed__EnableDemoData = "true"
dotnet run --project .\NaryadAi\NaryadAi.csproj --launch-profile http
```

Набор содержит 4 участка, 25 единиц оборудования, 2 мастеров, 15 исполнителей в 3 бригадах, 20 шифров неисправностей, 40 материалов и 500 нарядов за три месяца. В нём есть повторные неисправности конвейера CV-07 и возвраты одного исполнителя для демонстрации аналитики и рейтинга. Если в базе уже есть производственные справочники или наряды, заполнение отменяется без изменений.
